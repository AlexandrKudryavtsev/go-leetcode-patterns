# Queue

**Queue** — это паттерн задач, где основной структурой данных для решения является очередь (FIFO): первым пришел - первым вышел.

## Флаги

Обычно задача сводится к идее:

> элементы нужно обрабатывать в том же порядке, в котором они появились

Частые признаки queue-задач:

- нужно обслуживать элементы по очереди:
	- запросы
	- клиенты
	- задачи
	- события

- важен порядок прихода элементов:
	- первый пришёл → первый обработался
	- старые элементы нужно удалять раньше новых

- есть ограничение по времени или окну:
	- хранить только последние `k` элементов
	- хранить элементы за последние `t` секунд
	- удалять устаревшие элементы из начала

- задача похожа на симуляцию процесса:
	- очередь ожидания
	- круговая очередь
	- cooldown
	- пошаговая обработка

- нужно постоянно брать самый старый необработанный элемент

## Примеры

### [Number of recent calls](https://leetcode.com/problems/number-of-recent-calls)

Задача: подсчитать количество запросов за последние 3000 миллисекунд.

Нужно хранить только недавние элементы и удалять старые → queue

```go
type RecentCounter struct {
	queue []int
}

func Constructor() RecentCounter {
	return RecentCounter{
		queue: []int{},
	}
}

func (this *RecentCounter) Ping(t int) int {
	this.queue = append(this.queue, t)

	for this.queue[0] < t - 3000 {
		this.queue = this.queue[1:]
	}

	return len(this.queue)
}
```

Идея:

- В очереди хранятся только запросы из диапазона [t-3000, t]
- Новый запрос всегда добавляется в конец очереди
- Пока первый элемент слишком старый, удаляем его из начала
- После удаления устаревших элементов длина очереди равна количеству недавних запросов


### [Dota2 Senate](https://leetcode.com/problems/dota2-senate/)

Задача: смоделировать результат битвы сенаторов.

Симуляция процесса и круговая очередь оиждания → queue

```go
func predictPartyVictory(senate string) string {
	r := []int{}
	d := []int{}

    n := len(senate)

    for i, v := range senate {
        if v == 'R' {
            r = append(r, i)
        } else {
            d = append(d, i)
        }
    }

    for len(r) > 0 && len(d) > 0 {
        ri := r[0]
        di := d[0]

        r = r[1:]
        d = d[1:]

        if ri < di {
            r = append(r, ri+n)
        } else {
            d = append(d, di+n)
        }
    }

    if len(r) == 0 {
    	return "Dire"
    }

	return "Radiant"
}
```

Идея:

- Создаем две очереди: `r` — сенаторы Radiant, `d` — сенаторы Dire
- В очередях хранятся индексы сенаторов
- Сравниваем первых сенаторов из очередей:
	- меньший индекс ходит раньше и запрещает ход сопернику
	- победивший сенатор возвращается в конец своей очереди
- При возвращении добавляем `n` к индекс. Это переносит сенатора в следующий круг голосования и сохраняет порядок ходов
- Когда одна из очередей становится пустой, другая сторона побеждает
