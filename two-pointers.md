# Two pointers

**Two pointers** - это паттерн задач, где два указателя проходят по массиву или строке.

Один указатель обычно читает элементы, другой - сравнивает или показывает место для записи.

## Флаги

Если нужно:

- найти пару элементов
- проверить строку на палиндром
- удалить или сжать элементы на месте
- перенести одни элементы в начало или конец
- работать с отсортированным массивом

Если напрашиваются два вложенных цикла, стоит проверить вариант с двумя указателями.

## Частые варианты

### С двух концов

Один указатель в начале, второй - в конце.

```go
left := 0
right := len(nums) - 1

for left < right {
	// сравниваем nums[left] и nums[right]
}
```

Для задач на палиндромы и пары в отсортированном массиве.

### Чтение + запись

Один указатель читает элементы, второй показывает место для записи.

```go
write := 0

for i := 0; i < len(nums); i++ {
	// i читает элементы
	// write показывает, куда записывать
}
```

Для задач на удаление, сжатие и перестановку элементов без дополнительного массива.

## Примеры

### [Move Zeroes](https://leetcode.com/problems/move-zeroes)

Задача: перенести нули в конец и сохранить порядок ненулевых элементов.

Надо делать перестановку в на месте → two pointers

```go
func moveZeroes(nums []int) {
	write := 0

	for i := 0; i < len(nums); i++ {
		if nums[i] != 0 {
			nums[write], nums[i] = nums[i], nums[write]
			write++
		}
	}
}
```

Идея: двигать в начало все ненулевые элементы.

- `i` читает элементы;
- `write` показывает место для следующего ненулевого элемента;
- до `write` лежат найденные ненулевые элементы в правильном порядке.

Если `nums[i] != 0`, элемент ставится на позицию `write`, а `write` двигается вправо. Нули отдельно трогать не нужно: они останутся справа после обменов.
