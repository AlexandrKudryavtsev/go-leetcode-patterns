# Two pointers

**Two pointers** - это паттерн задач, где два указателя проходят по массиву или строке.

Один указатель обычно читает элементы, другой - сравнивает или показывает место для записи.

## Флаги

Часто подходит, если нужно:

- найти пару элементов
- проверить строку на палиндром
- проверить, является ли строка подпоследовательностью другой
- сравнивать две строки или два массива по порядку
- удалить или сжать элементы на месте
- перенести одни элементы в начало или конец
- работать с отсортированным массивом

Если в условии важен порядок элементов и часть элементов можно пропускать, тоже стоит подумать про два указателя.

Если напрашиваются два вложенных цикла, стоит проверить вариант с двумя указателями.

## Частые варианты

### С двух концов

Один указатель в начале, второй - в конце.

```go
left := 0
right := len(nums) - 1

for left < right {
	// сравниваем nums[left] и nums[right]
}
```

Для задач на палиндромы и пары в отсортированном массиве.

### Чтение + запись

Один указатель читает элементы, второй показывает место для записи.

```go
write := 0

for i := 0; i < len(nums); i++ {
	// i читает элементы
	// write показывает, куда записывать
}
```

Для задач на удаление, сжатие и перестановку элементов без дополнительного массива.

## Примеры

### [Move Zeroes](https://leetcode.com/problems/move-zeroes)

Задача: перенести нули в конец и сохранить порядок ненулевых элементов.

Надо переставлять элементы на месте → two pointers

```go
func moveZeroes(nums []int) {
	write := 0

	for i := 0; i < len(nums); i++ {
		if nums[i] != 0 {
			nums[write], nums[i] = nums[i], nums[write]
			write++
		}
	}
}
```

Идея: двигать в начало все ненулевые элементы.

- `i` читает элементы;
- `write` показывает место для следующего ненулевого элемента;
- до `write` лежат найденные ненулевые элементы в правильном порядке.

Если `nums[i] != 0`, элемент ставится на позицию `write`, а `write` двигается вправо. Нули отдельно трогать не нужно: они останутся справа после обменов.

### [Is Subsequence](https://leetcode.com/problems/is-subsequence)

Задача: проверить, можно ли получить `s` из `t`, удалив часть символов без изменения порядка.

Нужно проверить порядок символов, пропуская лишние → two pointers

```go
func isSubsequence(s string, t string) bool {
	i := 0

	for j := 0; j < len(t) && i < len(s); j++ {
		if s[i] == t[j] {
			i++
		}
	}

	return i == len(s)
}
```

Идея:

- `i` показывает следующий нужный символ из `s`
- `j` проходит по строке `t`
- если `s[i] == t[j]`, нужный символ найден и `i` двигается дальше

### [Container with most water](https://leetcode.com/problems/container-with-most-water)

Задача: найти две линии, которые образуют контейнер с максимальной площадью.

Нужно выбрать две границы контейнера → two pointers с двух концов

```go
func min(a, b int) int {
	if a > b {
		return b
	}

	return a
}

func maxArea(height []int) int {
	i, j := 0, len(height)-1

	area := (j - i) * min(height[i], height[j])

	for i != j {
		if height[i] < height[j] {
			i++
		} else {
			j--
		}

		newArea := (j - i) * min(height[i], height[j])
		if newArea > area {
			area = newArea
		}
	}

	return area
}
```

Идея: короткая линия и дистанция между элементами определяют площадь. Значит надо двигать указатель, стоящий на короткой линии. Тогда площадь может увеличиться.

- Сначала в `area` кладем площадь по первой и последней линии
- Если линия `i` меньше чем линия `j`, то имеет смысл попробовать подвинуть вправо посмотреть новую площадь
- В противном случае уменьшаем `j` и смотрим также на новую площадь


### [Max number of k sum pairs](https://leetcode.com/problems/max-number-of-k-sum-pairs)

Задача: найти максимум пар с суммой `k`, удаляя каждую найденную пару из массива.

Нужно искать пары с суммой `k`, не используя элементы повторно → two pointers

```go
import "sort"

func maxOperations(nums []int, k int) int {
	sort.Ints(nums)
	i, j, count := 0, len(nums) - 1, 0

	for i < j {
		if nums[i]+nums[j] == k {
			count++
			i++
			j--
		} else if nums[i]+nums[j] < k {
			i++
		} else {
			j--
		}
	}

	return count
}
```

Идея:

- Сортируем массив
- если сумма меньше `k`, двигаем левый указатель вправо
- если сумма больше `k`, двигаем правый указатель влево
- если сумма равна `k`, нашли пару и двигаем оба указателя
